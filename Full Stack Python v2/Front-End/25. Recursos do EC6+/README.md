# Exercício ES6+ - Filtragem de Alunos

Este projeto demonstra o uso de recursos modernos do JavaScript (ES6+) com Babel para transpilação.

## 📋 Descrição

O projeto implementa:
- ✅ Array de objetos com nome e nota de alunos
- ✅ Função que retorna alunos com nota >= 6
- ✅ Uso de recursos ES6+ (arrow functions, destructuring, template literals, etc.)

## 🚀 Recursos ES6+ Utilizados

- **Arrow Functions**: Sintaxe mais concisa para funções
- **Destructuring**: Extração de propriedades de objetos
- **Template Literals**: Interpolação de strings
- **Array Methods**: `filter()`, `forEach()`, `reduce()`
- **ES6 Modules**: Import/Export
- **Const/Let**: Declaração de variáveis com escopo de bloco

## 🛠️ Tecnologias

- JavaScript ES6+
- Babel (transpilação)
- Node.js

## 📦 Instalação

```bash
npm install
```

## 🎯 Execução

### Desenvolvimento (com watch):
```bash
npm run dev
```

### Build para produção:
```bash
npm run build
```

### Executar código compilado:
```bash
npm start
```

## 📊 Resultado

O programa exibe:
- Lista de todos os alunos
- Lista dos alunos aprovados (nota >= 6)
- Estatísticas da turma (total, aprovados, taxa de aprovação, médias)
